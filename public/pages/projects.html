Projects

Experienced Nascent consultants have been directly responsible for consultancy, technical leadership and project mentoring for a number of successful security and trusted-environment related projects.



Internet ID Strong Authentication Solution

Internet ID has been widely acclaimed as the first smartcard-based dual-factor strong (PKI) authentication solution for Internet Banking in Latin America. The project scope covered card application design, browser plug-ins, cryptographic data preparation, card generation, remote application administration and host authorization processes.

The original project, designed, implemented and deployed in record time, has evolved into a fully standards compliant solution including Cryptographic Middleware for Windows and Linux environments, as well as incorporating a remote application provisioning process and advanced innovative security countermeasures.

Private Label EMV Application

Full-feature EMV compliant private-label debit and credit application for the highly secure MULTOS smart-card platform, including advanced security functions such as CDA, customized risk management for offline transactions, delegated PIN-sharing and administration.

Designed, implemented and tested to the latest CCD specifications, the application is used daily on millions of debit cards in Brazil, offering unbeaten security, flexibility, standards compliance, yet maintaining issuer independence. This award-winning project, issued jointly with the Internet ID PKI application, has been spoken about at numerous international conferences.

Multi-application Card Management System

Multi-application smart-card Card Management System with remote provisioning functions including application loading, removal and updating, data preparation, personalization script generation and secure data delivery to on-card applications via GlobalPlatform™ Secure Channels.

The flexible provisioning process integrates MULTOS™ and Javacard™ remote load technologies, through the innovative use of a card-based Issuer Security Domain application on MULTOS, as well as supporting a range of different card models and operating system versions.

EMV Authorization Library

Full-grade multi-standard EMV Authorization Library supports private label EMV cards, EMV CCD, Mastercard M/Chip and VISA VSDC, as well as card-generated CAP/DPA-style one-time-passwords. Fully portable by design, the library incorporates a Cryptographic Abstraction Layer, and thus runs on multiple platforms, including the IBM z/OS ICSF, Linux and Windows.

Easily integrated into existing card authorization and management systems, the library has seen constant high-volume use since 2005 for full-grade cryptographic EMV transaction authentication, as well as secure scripting functions including remote PIN unblock and change.
